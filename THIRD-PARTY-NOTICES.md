Its streaming overlap-add implementation is derived from VoxLock 1.1.1 (Apache-2.0). SoXR remains a separate replaceable DLL; its upstream source archive and the build-system patches are included in the native release's `licenses` folder. It does not bundle a Python interpreter. The historical Python dependency list below applies to the older release and developer evaluation tools.
